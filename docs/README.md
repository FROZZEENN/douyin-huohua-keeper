## 写作约定

- **截图要脱敏**。好友昵称、头像、聊天内容一律马赛克或替换成示例数据。
- **命令可直接复制**。不要写 `<你的路径>` 这种需要替换的占位符而不给例子。
- **先说结论再说原因**。读者在排障时是急躁的，别让他翻到第三段才看到答案。
- **承认不确定性**。抖音前端会变，写「当前版本下有效」比写「一定可行」诚实。

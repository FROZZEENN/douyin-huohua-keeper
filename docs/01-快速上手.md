# 01 · 快速上手

> 目标：从零到**发出第一条消息**。全程约 15 分钟（不含下载 Chromium 的时间）。
> 遇到卡点先看 [05 · 故障排查](05-故障排查.md)。

## 0. 先确认三件事

| 你需要 | 怎么确认 |
|---|---|
| Python 3.11 或更高 | `python -V` |
| 一台**有图形界面**的电脑 | 首次登录要扫码，还可能需要填验证码 —— **服务器上做不了这一步** |
| 能访问 douyin.com | 浏览器打开一下试试 |

> ⚠️ **顺序很重要**：先在**有界面的电脑上完成登录**，再把登录态拷到服务器。
> 反过来一定卡在「需在手机上进行确认」。

## 1. 安装

```bash
git clone https://github.com/FROZZEENN/douyin-huohua-keeper.git
cd douyin-huohua-keeper

python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate

pip install -r requirements.txt
pip install -e .
playwright install chromium chromium-headless-shell
```

> 两个浏览器**都要装**：无头模式用的是 `chromium-headless-shell`，
> 只装 `chromium` 的话无头跑起来会报 `Executable doesn't exist`。

不想一步步敲的话（Linux / macOS / Git Bash）：

```bash
./scripts/dev.sh setup
```

Windows 原生（不需要 Git Bash）：

```powershell
.\scripts\dev.ps1 setup
```

## 2. 生成配置

```bash
cp .env.example .env
```

至少要改**工作台令牌**（它是唯一的门禁）：

```bash
python -c "import secrets;print(secrets.token_urlsafe(32))"
```

把输出填进 `.env` 的 `HUOHUA_TOKEN=`。

## 3. 启动

```bash
python -m douyin_huohua_keeper
```

打开 <http://127.0.0.1:8787>，输入刚才那个令牌。

## 4. 首次登录（扫码）

账号页 → 「扫码登录」→ 用抖音 App 扫码 → 手机上确认。

- 如果弹出**二次验证**：页面上会显示「登录页实时画面」，按提示填写即可。
- 登录成功后，登录态存在 `data/accounts/main.state.json`。
  **这个文件等同密码**，别外传、别放网盘。

## 5. 选人

收件人页 → 「同步好友列表」→ 打开你要发的人的开关。

> 新同步进来的人**默认是关闭的** —— 这是刻意的，避免手一滑就发给所有人。

## 6. 先演练一遍

首页勾选「**演练**」，再点「立即发送一次」。

演练会完整走一遍流程（选人、打开会话、找输入框），但**不点发送** —— 对好友零影响。
建议第一次都先跑一遍演练。

## 7. 真的发一条

去掉「演练」，点「立即发送一次」，然后看首页横幅的结果。

三种结果的含义：

| 结果 | 意思 |
|---|---|
| 成功 | 已确认送达（消息区里多了一条） |
| **结果不确定** | 消息**可能已发出**，但没能确认（不会自动重发，避免重复发送） |
| 失败 | 确实没发出去，横幅会列出是谁、为什么 |

## 8. 部署到服务器（可选）

```bash
# 只拷登录态这一个文件
scp data/accounts/main.state.json root@<你的服务器>:/opt/douyin-huohua-keeper/data/accounts/

# 服务器上
cd /opt/douyin-huohua-keeper
docker compose up -d
```

更多部署方式（Docker / systemd / cron）见 [README](../README.md)。

## 9. 出问题先自检

```bash
python scripts/healthcheck.py          # 14 项自检，人读
python scripts/healthcheck.py --json   # 机器可读
```

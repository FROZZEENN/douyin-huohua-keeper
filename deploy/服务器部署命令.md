## 1. 本机：把项目传上去（Git Bash，项目根目录）

```bash
SERVER=root@<你的服务器IP> KEY=<你的私钥路径> bash deploy/sync-to-server.sh
# 例：SERVER=root@<你的服务器IP> KEY=~/.ssh/alihua .bash deploy/sync-to-server.sh
```
传完自动把 `.env.server` 复制成服务器上的 `.env`。

## 2. 服务器：装 Docker（首次，SSH 登录后）

```bash
ssh root@<你的服务器IP>

# 装 docker + compose 插件
apt-get update
apt-get install -y ca-certificates curl
install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
chmod a+r /etc/apt/keyrings/docker.asc
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] \
  https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo $VERSION_CODENAME) stable" \
  > /etc/apt/sources.list.d/docker.list
apt-get update
apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

systemctl enable --now docker      # 开机自启
docker --version && docker compose version
```

> 国内拉镜像慢的话，可选配镜像加速：在 `/etc/docker/daemon.json` 写
> `{"registry-mirrors":["https://docker.m.daocloud.io"]}` 后 `systemctl restart docker`。

## 3. 服务器：生成证书 + 起服务

```bash
cd ~/douyin-huohua-keeper

# 3.1 自签证书（私钥只在服务器生成）
SERVER_IP=<你的服务器IP> bash deploy/nginx/gen-selfsigned.sh

# 3.2 起服务（基础 compose + HTTPS 覆盖层）
docker compose -f docker-compose.yml -f docker-compose.https.yml up -d --build
# 首次 build 会拉 ~600MB（Playwright Chromium），100Mbps 约 1 分钟

# 3.3 看状态与日志
docker compose -f docker-compose.yml -f docker-compose.https.yml ps
docker compose -f docker-compose.yml -f docker-compose.https.yml logs -f
```

浏览器打开 `https://<你的服务器IP>/` → 告警点「继续前往」→ 输令牌登录。

## 5. 常用运维

```bash
cd ~/douyin-huohua-keeper
COMPOSE="docker compose -f docker-compose.yml -f docker-compose.https.yml"

$COMPOSE logs -f --tail=100      # 看日志
$COMPOSE restart nginx           # 重启 nginx
$COMPOSE restart keeper          # 重启工作台
$COMPOSE down                   # 停

# 证书一年后到期，续期：
SERVER_IP=<你的服务器IP> bash deploy/nginx/gen-selfsigned.sh
$COMPOSE restart nginx
```

## ⚠️ 预期管理

- **首次登录不用重做**：本地 `data/accounts/main.state.json` 已随项目传上去。
- **登录态 7~30 天会失效**，失效后必须**人工重新扫码**——建议在电脑前（可能触发二级身份验证），
  用工作台「扫码」页重新登录，状态写回服务器 `data/accounts/main.state.json`。
- **自动发送**（每天 ~09:30 给 `.p` 发「1」）可长期无人值守，失败会走 Server酱 推微信。
